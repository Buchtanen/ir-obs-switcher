# Naming convention

Formát: `pl-{scope}-{order}-{layer}-{variant}.{ext}`.

- `pl` = PITWALL LIGHT;
- scope: `hunting`, `hunted`, `battle`, `lap`, `pb`, `position`, `final-lap`, `finish`, `bio`, `sysinfo`, `ble`;
- číselné pořadí template vrstvy určuje defaultní z-index;
- stavová barva je v názvu jen u samostatné state vrstvy;
- rozlišení je adresář `1x` nebo `2x`, ne suffix souboru;
- SVG je master, PNG/WebP jsou odvozené exporty se stejným stemem.
