# i18n

Dva **oddělené** slovníky. Nemíchat.

## Dashboard (GR/VR) — `i18n.py`

Jazyky: CS, EN, DE, FR, SP, PL, HU. Default CS. `[app] language`. `set_language` při startu.

Stringy UI switcheru (Připojeno, scény, OAuth, …). Testy: `tests/test_i18n.py`. Docs: [LOCALIZATION.md](../../../LOCALIZATION.md).

## Overlay HUD — `overlay/i18n.py`

Jazyk overlay (`[overlay] language`) + tokeny karet (headline/status). V4 copy může jít z theme/manifestu.

Časy na HUD: **ne** i18n překlad, ale formát iRSDK (`m:ss.fff`) — skill `iracing-sdk-display-format`.

Testy: `tests/test_overlay_i18n.py`, `tests/test_overlay_i18n_v4.py`.
